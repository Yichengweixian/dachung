# 软件著作权登记材料清单与说明

> 对应研究单元 U13R01（研究原型）。本文件用于软著登记的说明材料准备，不虚构未实现功能。

## 1. 软件名称（建议）

风光储容量配置与逐时平衡研究工作台（V1.0）

## 2. 软件分类与用途

- 分类：能源系统分析与优化计算类应用软件
- 用途：面向风光储联合系统的逐时功率平衡计算、储能容量—功率联合寻优、方案对比与结果导出
- 用户：本项目研究人员；不面向生产调度或电网运行控制

## 3. 运行环境

- 操作系统：Windows（本项目实测环境为 Windows 桌面版）
- 运行时：Python 环境 + Streamlit 本地服务；具体解释器与依赖库版本以运行记录
  `results/prototype/U13R01-v01/run_manifest.json` 的 `packages` 字段为准（不在此处手抄版本号）
- 硬件：普通办公计算机即可运行；本实例 101 候选求解在本机完成
- 网络：仅数据下载阶段需要访问公开气象接口；软件本体运行不依赖外部服务

## 4. 安装与启动

1. 安装 Python 运行环境并创建项目虚拟环境；
2. 安装依赖（依赖清单见 `requirements.txt`）；
3. 在项目根目录执行本地服务启动命令，服务仅监听本机回环地址、关闭使用统计；
4. 浏览器访问本机地址进入界面。

## 5. 功能清单（七个模块）

| 模块 | 功能 | 对应实现 |
|---|---|---|
| 1 数据导入 | 内置 24h 构造算例、168h 气象输入、8760h 年度输入，并支持同字段 CSV 上传 | `src/prototype_service.py: read_input` |
| 2 参数设置 | 储能容量与 SOC、火电约束、经济参数可视化设置；支持参数 JSON 导入/导出，仅作用于当前会话 | 同上前端表单 + `parameters_from_json` |
| 3 平衡计算 | 规则模式与 MILP 模式两种逐时调度，输出功率平衡、SOC 与残差 | `src/study_runtime.py`、`src/storage_model.py`、`src/optimization_model.py` |
| 4 网格寻优 | 24h 输入下的 101 候选容量—功率联合寻优 | `src/grid_search.py` |
| 5 方案对比 | 将多次计算结果加入会话内对比表并出图 | `web/app.py` 第 03 页签 |
| 6 图表 | 调度三联图与网格成本热力图 | `src/prototype_service.py: dispatch_figure / grid_figure` |
| 7 导出 | 逐时 CSV、汇总 CSV、网格 CSV、图表 PNG、参数 JSON | `csv_bytes` / `png_bytes` |

## 6. 界面说明

- 左侧边栏：数据来源选择、调度模式切换、储能与火电参数、经济参数、参数导出
- 页签 01 调度验证：计算按钮、四个关键指标（消纳率、弃电量、缺供电量、总成本）、调度图、导出按钮、方案对比入口
- 页签 02 容量寻优：101 点网格运行、最优配置提示、成本热力图与候选明细表
- 页签 03 方案对比：会话内结果对比表与总成本柱状图
- 页签 04 数据与说明：输入数据表、单位与口径说明、研究边界提示

界面一律显示"研究原型 · 构造算例（非真实电网数据）"标识，并对长时段输入给出限制提示，
不做隐式截断；修改输入或参数后旧结果自动失效。

## 7. 技术特点

1. 所有模型公式集中在公共计算模块，界面不重复实现公式，便于审核；
2. 计算结果带求解状态与物理审计结果，审计不通过时不发布结果；
3. 结果与参数、输入哈希绑定，可回溯；
4. 数据仅在本机处理，不上传外部站点。
