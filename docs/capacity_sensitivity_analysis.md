# 第5阶段：储能容量敏感性分析

本次五组24小时仿真表明：储能容量从0增加到80 MWh，新能源消纳率从89.63%提高到92.72%，弃风弃光电量从225.68 MWh降至158.31 MWh。各相邻容量区间的改善幅度相同，0至80 MWh范围内尚未出现新能源消纳收益递减。该结果来自既有构造测试数据，用于理解规则调度，不代表实际地区的实测运行结果。

本文只记录分析。程序入口为run_capacity_sensitivity.py，计算模块为src/capacity_sensitivity.py，绘图模块为src/plot_capacity_sensitivity.py。仿真数值保存在results/capacity_sensitivity/summary.csv。

固定非零容量场景的功率为20 MW，可以观察能量容量变化的作用。0 MWh场景功率为0，代表无储能。其他参数沿用第4阶段：初始SOC为50%，范围10%至90%，充电效率与放电效率均为0.95。每组仿真独立初始化；本次没有要求期末SOC回到初值，所有非零容量场景最终均为10%。

调度仍为风光富余时先充电、剩余弃电；风光不足时先由储能放电，再由火电补缺，仍不足则失负荷。容量场景是预先给定的，没有搜索最优值。

## 2. 指标定义

设每个时段的风光总出力为R，弃电功率为C，步长为Δt：

- 新能源可发电量：ΣR×Δt。
- 新能源消纳电量：Σ(R−C)×Δt，包含直接供给负荷和进入储能的新能源。
- 新能源消纳率：新能源消纳电量÷新能源可发电量×100%。
- 弃风弃光率：弃风弃光电量÷新能源可发电量×100%。
- 弃风弃光电量、火电发电量、失负荷量及储能充放电量，均由相应功率对时间求和，单位MWh。
- 储能利用率：发生充电或放电的时段时长÷总仿真时长×100%，活跃功率阈值为10⁻⁶ MW。该指标描述参与调度的时长，不表示循环效率或满功率利用率。无储能场景为“不适用”，CSV留空。

充放电量在电网侧计量，SOC在电池侧根据效率递推。新能源消纳包含充电过程中及后续放电中的损耗，不能直接理解为最终由新能源供给负荷的电量占比。若新能源可发电量为0，相关比例不定义；本次各组分母均为2175.84 MWh。

## 4. 为什么容量增加能提高新能源消纳率

本日10至14时段风光出力超过负荷。无储能时，这些富余电量全部弃掉；加入储能后，部分电量进入电池，随后在风光不足时放出。容量越大，在相同SOC范围下可用的电量空间越大，因此能够承接更多午间富余新能源。

本次20至80 MWh各组在午间充电前都已降至SOC下限10%，午间能够充至90%，之后再次放至10%。设额定容量为E，可用电池能量空间为0.8E。考虑0.95的充电效率，电网侧需要的充电量为：

充电量 = 0.8E ÷ 0.95。

所以，每增加20 MWh额定容量，本日额外接纳的新能源为0.8×20÷0.95≈16.8421 MWh，新能源消纳率提高约16.8421÷2175.84×100=0.7741个百分点。

## 5. 边际收益是否已经递减

“边际收益”在这里指每增加一单位能量容量带来的技术指标改善，不包含投资回报。程序另外保存marginal_changes.csv，直接计算相邻场景的差值与单位容量增益。

| 容量区间 / MWh | 消纳率提高 / 百分点 | 弃电减少 / MWh | 火电减少 / MWh |
|---|---:|---:|---:|
| 0→20 | 0.7741 | 16.8421 | 22.8000 |
| 20→40 | 0.7741 | 16.8421 | 22.8000 |
| 40→60 | 0.7741 | 16.8421 | 22.8000 |
| 60→80 | 0.7741 | 16.8421 | 22.8000 |

在本次区间内，每增加1 MWh储能容量，减少约0.8421 MWh弃电，消纳率提高约0.03870个百分点。五组数据没有显示边际收益递减，不能把一般规律写成本次已经观察到的结论。

容量进一步增大后，额外空间可能无法充分使用，原因包括：

1. 富余新能源电量有限。能够转移的电量存在上限，储能容量再大也不能产生新的富余新能源。
2. 充电功率与富余时段长度有限。固定20 MW意味着每小时最多从电网侧吸收20 MWh，增加能量容量不会提高这一充电速度。
3. 放电功率与缺电时段长度有限。已经存入的电量也需要合适时段才能释放，剩余空间的重新形成受时序影响。

本算例可以直接计算充电端的限制：10至14时段共5小时，每小时富余功率都超过20 MW，因此固定功率下最多接纳5×20=100 MWh新能源。对应电池能量增加为95 MWh。若充电开始时SOC为10%，容纳这些能量至少需要95÷0.8=118.75 MWh额定容量。这个数值是依据输入曲线和功率上限推导的容量尺度，超出本次五组仿真范围，不是优化结果，也不是经济最优容量。

当充电端已达到这个100 MWh上限，继续增加能量容量将无法进一步增加本日新能源接纳量，相关收益会进入平台。在这组简化数据中，也可能出现从近似线性增长直接转入平台，而不是逐渐弯曲的曲线。固定20 MW、有限充电时段造成的上限与真实投资收益需分别讨论。

## 6. 为什么放电量大于充电量，火电减少量也更大

各组初始SOC相同，但容量越大，初始自带电量也越多。期末SOC为10%，低于初始50%，意味着本日额外使用了初始库存。本次电网侧放电量满足：

放电量 = 充电量×0.95×0.95 +（初始电量−期末电量）×0.95。

以80 MWh场景为例：本日充电67.3684 MWh，考虑两次效率后对应60.80 MWh放电；初始40 MWh、期末8 MWh，库存净减少折算到电网侧为30.40 MWh。两部分合计91.20 MWh，等于火电发电量的减少值。

每增加20 MWh容量，火电减少的22.80 MWh中，15.20 MWh对应本日新能源充电经损耗后的供电，7.60 MWh来自额外的初始库存净减少。summary.csv保留initial_energy_MWh、final_energy_MWh、energy_change_MWh、initial_inventory_supply_MWh及损耗列，供复核这一能量账目。

因此，不能把全部火电减量都归因于本日弃电转移，也不能把这一天结果直接乘365作为持续年度收益。后续若要研究长期运行或经济性，需要另行确定期末SOC约束或连续运行边界。本阶段沿用既有规则，未增加这些约束。
