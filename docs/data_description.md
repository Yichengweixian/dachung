# 24小时基础测试数据说明

## 数据性质与字段

data/input_24h.csv是为模型开发构造的示例数据，不来自实际电网、气象观测或历史申报书图表。CSV字段严格使用hour、load、wind、solar。

hour为0至23，分别代表00:00—01:00至23:00—24:00。每行功率解释为该小时的平均功率，单位MW。没有指定真实日期、季节或地区。wind和solar均表示可用出力，尚未扣除弃风弃光。

这四个简短字段对应前期指标文档中的负荷、风电可用出力和光伏可用出力概念；后续建模读取时应沿用或明确映射，不改变含义。

## 构造方法与假设

- 负荷：采用显式24点典型曲线。凌晨低谷81 MW，9点早高峰145 MW，午间回落，19点晚高峰162 MW。数值可在config/data_24h.json中逐项调整。
- 风电：假设装机100 MW，基础容量因子0.50，叠加振幅0.12的日周期余弦趋势，再加入标准差4 MW的正态扰动。扰动使用0.25、0.50、0.25三点加权平滑，最后限定在0至100 MW。随机种子20260910。这里构造的是连续出力形状，不是风速到风机功率的物理模型。
- 光伏：假设装机150 MW，6点至18点之间采用正弦函数的1.6次方构造日间形状。6点及以前、18点及以后严格为零，12点达到150 MW。该简化曲线用于小时模型测试，不模拟具体地点的日出日落。
- 所有输出功率保留两位小数，风光总出力在绘图时由CSV中的wind与solar相加得到。

风光合计装机250 MW，相当于162 MW负荷峰值的154.32%，用于构造新能源出力较高且存在时序错配的测试环境。这是“新能源装机/峰值负荷”比值，不能称为新能源占全部电源装机的比例；火电装机尚未确定。脚本另外输出“风光可发电量/负荷电量”，它不是新能源消纳率。

## 运行与检查

在项目目录运行run_data_24h.py，先生成并校验数据，再保存CSV、读回CSV并绘图。重复运行会按同一配置重新生成上述CSV和图片；手工编辑前应另存副本。此入口固定生成24小时数据，不读取simulation.json中的时间步数，168小时扩展需后续独立设计。

检查包括24个连续且不重复的小时、非负有限数据、风光不超过装机、夜间光伏为零、中午光伏峰值、负荷早晚双峰、风电存在波动且相邻小时变化不超过15 MW，以及风光相对负荷既有富余也有不足。

“风光富余”仅表示wind + solar > load；“风光不足”仅表示wind + solar < load。尚未加入火电、储能、外送或运行约束，不能将两者直接称为弃电或失负荷，也没有进行储能优化。
