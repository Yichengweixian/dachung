# 年度与典型日分析 v02

武汉2023年完整UTC气象，经U10同公式转换、光伏显式封顶150MW；负荷仍为构造形状，非真实电网数据。
原始数据：data/raw/U11R02-v01/main/；正式输入：results/annual/U11R02-v01/input_8760h.csv。
数据未插补，8760小时完整。封顶事件0、削减0MWh，详见solar_cap_events.csv及run_manifest.json。

每天风光荷各除自身峰值（零峰值用1），拼72维特征。KMeans++、n_init=10、N=8/10/12，种子42与7。
归一化用于按形状分组，调度使用各簇成员原始MW曲线均值，不把归一化中心直接当作MW。
天数权重总和365、概率权重总和1；先合计电量再计算年度比例，不平均各日百分率。
储能40MWh/20MW，每个日初末SOC=0.5；365个日独立求解，不提供跨日储能或连续年调度结论。

## 结果

425次MILP全部Optimal并通过独立物理审计；聚类重复标签一致。
主种子N=8/10/12最坏指标误差分别6.713739、6.626989、6.434640个百分点；选定N=12仍不满足1个百分点标准。
种子7在N=12误差6.605393个百分点，亦未通过。N增大误差不增检查通过。
完整精度见results/annual/U11R02-v01/comparison.csv（seed、N、*_error_pp列）；年度全仿真值见full_annual.csv。
总体inconclusive：现有候选下典型日近似精度不足，不能报告为有效年度替代。

形状归一化弱化幅值差异、簇均值平滑极值、调度约束非线性，是可能的误差来源，尚未通过隔离实验逐项确证。
下一单元可预先冻结更多N或k-medoids比较，不回头调整当前参数或阈值。
