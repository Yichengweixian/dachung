# 第6阶段：系统经济性评价

本阶段保持第5阶段的24小时输入和规则调度不变，对0、20、40、60、80 MWh场景重新仿真，并计算火电、储能投资折算、储能运维、弃电惩罚和失负荷惩罚成本。非零容量场景功率均为20 MW，无储能场景功率为0。

使用本次示例参数，24小时综合成本从无储能的385980.00元降至80 MWh场景的363810.54元。80 MWh是这五个给定场景中成本最低的一组；曲线在测试范围内持续下降，尚未显示内部经济最优点。

本文与代码分开保存。运行入口为run_economics.py，成本模块为src/economic_model.py，绘图模块为src/plot_economics.py。原有规则调度没有引入价格决策，也未使用遗传算法或其他容量寻优算法。

## 1. 集中管理的示例参数

所有成本参数位于config/economics.json的parameters对象，metadata说明参数来源和计价范围。这些数值是人为设置的模型测试假设，没有引用文献，也不代表市场报价或实际项目成本。

| 参数字段 | 示例值 | 单位与含义 |
|---|---:|---|
| thermal_cost_CNY_per_MWh | 350 | 元/MWh，火电线性运行成本 |
| storage_energy_capex_CNY_per_kWh | 800 | 元/kWh，能量侧单位投资 |
| storage_power_capex_CNY_per_kW | 300 | 元/kW，功率侧单位投资 |
| storage_lifetime_years | 15 | 年，投资折算寿命 |
| discount_rate | 0.05 | 年折现率5%，输入使用比例 |
| storage_fixed_om_fraction_per_year | 0.02 | 每年按初始投资的2%计固定运维 |
| storage_variable_om_CNY_per_MWh_discharged | 10 | 元/MWh，按电网侧放电量计可变运维 |
| curtailment_penalty_CNY_per_MWh | 200 | 元/MWh，弃风弃光的模型惩罚系数 |
| load_shedding_penalty_CNY_per_MWh | 10000 | 元/MWh，失负荷的模型惩罚系数 |
| hours_per_year | 8760 | 小时/年，用于年度费用向仿真时段分摊 |

参数设置使失负荷的单位惩罚明显高于火电运行成本，便于后续检验供电不足造成的经济影响；弃电惩罚体现减少弃风弃光的评价权重。目前调度仍按既有优先规则运行，因此调整惩罚系数只改变成本评价，不会改变充放电或火电出力。

能量侧和功率侧投资分别计价，不能把同一完整系统报价重复填入两项。以后替换文献参数时，应同时核对币种、价格年份、单位、投资包含的设备范围，以及运维是否已含在其他单价中。本次不计残值、设备更换、补贴、税费或价格随年份变化；充电能量来自系统内新能源，不再额外设置购电费用。

## 2. 综合成本公式与时间尺度

按本项目所要求的综合口径，各项成本相加：

Total Cost = 火电成本 + 储能成本 + 弃电成本 + 失负荷成本。

储能成本 = 分摊到仿真时段的投资成本 + 固定运维成本 + 可变运维成本。

total_cost_CNY即本阶段要求的总成本，包含储能投资折算。它与纯运行费用有区别：CSV另列operating_cost_excluding_investment_CNY，表示从综合成本中扣除投资折算后的费用。

### 电量相关成本

每个场景已经按功率×时间步长汇总电量，单位均为MWh。成本模块直接使用这些电量，不再乘一次时间步长：

- 火电成本 = 火电发电量 × 350元/MWh。
- 弃电成本 = 弃风弃光电量 × 200元/MWh。
- 失负荷成本 = 失负荷量 × 10000元/MWh。
- 可变储能运维 = 储能放电量 × 10元/MWh。

可变运维只对放电量计费，不同时对充、放电量重复收费。弃电及失负荷成本是本模型的评价惩罚，不表示已经发生同等金额的实际罚款。

### 投资折算与固定运维

设能量容量为E MWh、功率容量为P MW，初始投资为I：

I = E × 1000 × 800 + P × 1000 × 300，单位元。

这里的1000将MWh转换成kWh、MW转换成kW，与投资单价对应。无储能时E=P=0，因此投资和运维均为0。

设折现率为r、寿命为n年，资本回收系数为：

CRF = r / [1 − (1+r)^(−n)]。

当r=0时，CRF=1/n，退化为不计折现的平均年度分摊。本次r=0.05、n=15，CRF≈0.0963422876。

设仿真总时长H=时间步数×步长，投资年化费用和固定运维均按H/8760分摊：

- 年化投资费用 = I × CRF。
- 本次投资折算 = I × CRF × H/8760。
- 本次固定运维 = I × 0.02 × H/8760。

本次H=24，因此分摊比例为1/365。只把这个时段的分摊费用计入Total Cost，不把整笔初始投资再加一次；固定费用按整个仿真时长分摊，也不按储能活跃时长打折。该分摊是一项会计评价约定，不表示已经验证这一天可以代表全年运行。

以40 MWh / 20 MW为例，初始投资为3800万元，本次投资折算10030.155970元、固定运维2082.191781元、可变运维456元，储能成本合计12568.347751元。

## 4. 为什么理论上可能存在经济性最优容量

储能容量较小时，可用于存放午间富余新能源的空间有限，因此更多风光电量被弃掉，弃电惩罚较高。风光不足时，也需要较多火电发电。适当增加容量，可以通过减少弃电和火电成本抵消新增储能费用。

容量继续增大时，初始投资及相应固定运维继续上升。但能够转移的富余新能源有限，而且充放电功率和可用时段有限。当新增容量无法充分充入或释放电量时，它带来的运行费用节省就会减少。

可以用相邻容量的增量关系理解这一权衡：

总成本变化 = 新增投资折算 + 新增固定及可变运维 − 火电成本节省 − 弃电成本节省 − 失负荷成本节省。

如果右侧小于0，增容降低总成本；如果大于0，增容提高总成本。收益由大变小、最后不足以覆盖增容费用时，可能出现内部最低点。但这不是必然结果：参数、数据或容量区间不同，最低值也可能落在0 MWh或所测容量上界。

本次20至80 MWh各相邻区间每增加20 MWh：

- 火电成本减少22.8 MWh×350=7980.00元。
- 弃电成本减少约16.8421 MWh×200=3368.42元。
- 储能投资折算增加约4223.22元、固定运维增加876.71元、可变运维增加228.00元，合计5327.94元。
- 总成本净减少约6020.49元。

0至20 MWh还需要新增整套20 MW功率侧投资，其24小时投资和固定运维分摊约1912.48元，因此首个区间只减少4108.01元。随后各非零容量场景功率相同，不再增加这部分功率侧费用。

由于第5阶段已经显示0至80 MWh的消纳改善近似线性，本次又采用线性投资和运行成本，正容量区间的总成本也呈近似直线。不能为了得到“先降后升”而人为修改结果，也不能据此声称80 MWh为最优配置。当前只得到了给定五组、当前规则和示例参数下的最低成本场景。

## 5. 初始储能电量对成本比较的影响

各场景SOC从50%开始，在10%结束，容量越大，自带并消耗的初始储能电量也越多。以80 MWh为例，初始40 MWh、期末8 MWh，净消耗32 MWh电池侧库存，折算到电网侧为30.4 MWh。按本次火电单价计，这部分供电对应10640元的火电替代价值。

因此，80 MWh相对无储能的火电成本减量31920元中，10640元与初始库存净消耗有关，21280元对应本日新能源充电经充放电损耗后的供电。不能把全部31920元都解释为当天减少弃电所带来的收益。

summary.csv单独保留initial_inventory_supply_MWh和initial_inventory_thermal_value_CNY，后者只按火电单价估计这一影响，不加进用户指定的Total Cost，也不等同于一次实际的SOC补足调度。本次没有引入额外的期末SOC约束或库存购入费用。

若以后用于持续运行或经济最优容量判断，需要在明确边界条件后统一初末SOC或连续运行方式，并采用真实参数。当前24小时费用不直接乘365当作已验证的年度经济结论。

| results/economics/run_manifest.json | 本次输入校验值、参数、依赖版本及核对记录 |
| figures/economics/capacity_vs_total_cost.png | 容量与24小时综合成本曲线，纵轴单位万元 |

summary.csv主要字段：total_cost_CNY为综合总成本，thermal_cost_CNY为火电成本，storage_cost_CNY为储能合计成本，curtailment_cost_CNY为弃电成本，load_shedding_cost_CNY为失负荷成本，renewable_utilization_pct为新能源消纳率，curtailment_rate_pct为弃电率。

储能成本可追溯至storage_investment_allocated_CNY、storage_fixed_om_CNY和storage_variable_om_CNY。storage_capex_CNY表示一次性投资总额，不能与已含投资折算的total_cost_CNY再次相加。simulation_hours、year_fraction和capital_recovery_factor记录费用折算依据。

经济性CSV保留17位有效数字，避免年化系数和时间比例先舍入、再乘以大额投资造成核对误差；阅读和展示时可按两位小数显示。
