# U09 储能容量—功率网格寻优

U09-20260913-01 完成。冻结网格包含 1 个零储能组合以及 10 个正容量×10 个正功率组合，共 101 个。主网格、反序重跑和高投资参数网格各 101 次 MILP 均获得 Optimal，两套约束检查通过；反序重跑的六项指标最大差为 0。

## 主结果

| 指标 | 零储能 | 网格内最低成本组合 |
|---|---:|---:|
| 储能配置 | 0 MWh / 0 MW | **70 MWh / 25 MW** |
| 24 h 综合成本 / CNY | 521,956.50 | **486,358.65** |
| 新能源消纳率 | 78.2654% | **83.4660%** |
| 弃电量 / MWh | 472.91 | **359.7528** |
| 火电发电量 / MWh | 1,221.07 | **1,122.37** |
| 失负荷 / MWh | 0 | **0** |
| 储能活跃时间占比 | 不适用 | **79.1667%** |

70 MWh / 25 MW 是唯一的样本最低点，且满足 0<E<100、5<P<50，因此按冻结判据 U09 为 `supported`。相对零储能，该组合的 24 h 综合成本低 35,597.85 CNY，消纳率高 5.2006 个百分点，弃电量少 113.1572 MWh。

综合成本直接由 U05 的 `src.economic_model.evaluate_system_costs` 评价，寻优层没有复制成本公式。最低点的储能当日投资分摊 16,760.92 CNY，固定运维 3,479.45 CNY，可变运维 1,338.22 CNY。

## 相邻网格边际

| 固定另一维 | 变化 | 成本相对 70/25 的变化 / CNY | 换算每单位变化 |
|---|---|---:|---:|
| P=25 MW | E: 60→70 MWh | −2,697.24 | −269.72 CNY/MWh |
| P=25 MW | E: 70→80 MWh | +423.40 | +42.34 CNY/MWh |
| E=70 MWh | P: 20→25 MW | −52.31 | −10.46 CNY/MW |
| E=70 MWh | P: 25→30 MW | +362.05 | +72.41 CNY/MW |

负号表示增加配置后成本下降。四个相邻点的成本均高于 70/25，与内部最低点一致。这是离散网格的局部边际，不是连续优化导数。

## 高投资参数稳健性

将能量侧投资从 800 提高到 1200 CNY/kWh、功率侧投资从 300 提高到 500 CNY/kW，其余不变后，样本最低点为 **70 MWh / 20 MW**，综合成本 496,610.83 CNY。功率向更小方向移动、容量保持，符合预定方向检查。这不表示对所有成本参数均稳健。

## 边界与限制

- 所有数据均为 24 h 构造算例，成本为示例参数；结果不是真实电网或项目投资结论。
- “70 MWh / 25 MW”只是冻结的离散候选集中最低成本点，不是连续空间全局最优；也未用真实全年序列验证。
- 现模型将火电视为全日必须运行的等值机组，未建模启停、最小开停机时间、备用和网络潮流。
- 24/8760 投资分摊是为与当日运行成本对齐的评价口径；该构造日不能自动代表全年。
