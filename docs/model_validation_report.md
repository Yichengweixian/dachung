## 事后复核更正

33.93 MWh公式没有扣除储能吸收：例如hour=1的公式值和充电量均为7.34 MW，实际新增弃电为0。三因素又混用了局部估算与顺序增量，无法组成统一分解。因此原方法本身无效，不应因“残差大且原因不明”记inconclusive。当前拆分结论为：独立数值验证supported；原归因设计invalid；U07整体记invalid，但不影响U06模型有效性。U07R是后续另行冻结的模型内会计分配，不反证原公式。
