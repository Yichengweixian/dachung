# U10 设计：真实气象数据管线

## 数据获取

- 来源：NASA POWER 官方 API（https://power.larc.nasa.gov/api/ 逐小时接口）
- 坐标：30.59, 114.30（武汉）；参数：太阳辐照度（ALLSKY_SFC_SW_DWN）、50m 风速（WS50M）
- 时段：优先选择**数据完整的历史年份**中连续 7 天（168h）；不使用未完整归档的近期日期
- **原始返回文件必须原样保存**到 `data/raw/`（含请求参数记录），不得只留处理后数据
- 下载脚本：`scripts/download_nasa_power.py`（独立可运行，供网络恢复后重跑）；API 失败时本单元判 blocked，脚本照常交付

## 转换模型（可解释、入文档）

- **风电**：三段式功率曲线——v<切入(3 m/s) 出力 0；切入≤v≤额定(12 m/s) 按风速立方插值到满发；额定<v≤切出(25 m/s) 满发；v>切出 为 0。标幺出力 × 装机 100 MW
- **光伏**：辐照度归一化（以 1000 W/m² 为基准）× 装机 150 MW；夜间辐照度为 0 时严格为 0
- **负荷**：现有 24h 形状 × 7 天，每天乘 0.95/1.0/1.05 轮换系数模拟日间差异；**文档明确写"负荷为构造形状，非真实负荷"**

## 输出

- `data/raw/`：原始 JSON/CSV + 请求参数记录
- `data/processed/input_168h.csv`：hour(0–167)、load、wind、solar，两位小数，通过 `validate_input_data` 校验
- 图：`figures/real_data/`（气象原始曲线 + 转换后风光荷曲线）
- `docs/real_weather_data_method.md`：来源、坐标、时间范围、单位、转换公式、局限性与复现方法（含下载脚本用法）

## 注意

- 读取 API 返回的单位与缺失值说明，不自行猜测单位
- 文件读写统一 `encoding="utf-8"`；哈希记录入本单元 findings
