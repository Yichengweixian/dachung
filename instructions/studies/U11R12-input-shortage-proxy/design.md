# 固定设计

任务组annual；2023年8760h输入原样使用U11R02-v01。N=48，种子按42、7、2026顺序，原U11R08B-v01标签与簇计数不变。不重新聚类、不使用已保存调度结果/成本/误差来选择日。

对每个实际日d，计算p_d=sum_h max(load_dh-wind_dh-solar_dh-Tmax,0)*1h，Tmax使用现有120MW火电上限。在每个原簇k中选择abs(p_d-mean(p_members))最小的成员。差距距离最小值不超过1e-12 MWh视为候选并列；并列时用原72维(load,wind,solar)/100MW特征到簇均值的欧氏距离，再以距最小值不超过1e-12的最早UTC实际日打破并列。无可调新系数，不特判seed7/簇26/某日期。该代理忽略储能、火电爬坡/下限及时序，不能等同真实缺供。

新选日期可能改变三通道输入，因此复用src/energy_calibrated_weights_resolved.py的同一校准算法重新拟合：0.5*c<=w<=2*c，sum w=365，三通道输入电量minimax、归一化L1偏移、日期序列字典序，层级带BAND=1e-6。CBC presolve off、primal/integerTolerance=1e-9，其他求解设置/物理门槛不变。每种子主校准与独立重复各50次LP，共300次。

仅验证原40MWh/20MW配置；原经济参数不变。每种子48个24h独立日MILP和簇0重复调度1次，共147次调度（144主+3重复）；原365日全年基准只读复核、零重求解。每日SOC重置且期末回初值，无跨日耦合。对照为同种子原U11R08B已校准N48结果，不更换为更差未校准对照。新的簇计数权重结果另外全量报告。

保存全365日p与原标签、每簇选择/并列证据、选取的24h输入、校准两轮所有阶段LP/MPS/CBC原生解与日志、代表日主/重复小时解、日汇总和三个种子完整comparison。不做容量迁移/更改N/调参/补试其他代理；所有旧输入、findings、freeze和产物保持只读。
