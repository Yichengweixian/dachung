# 冻结判据

范围/design、三种子、N48、单配置、选择规则、校准方法/数值带和预算不变。先冻结后实现/求解；未运行verdict=null。

有效性：旧依赖哈希、原配置/版本一致；原标签365行且覆盖48簇、每簇计数与旧代表日相等、候选属本簇/日期真实且不重复；代理值/导出值均有限。所有300次权重LP和147次调度MILP必须Optimal。权重边界/365总和绝对残差<=1e-6，校准归一化残差<=1e-7（沿用旧闸门），重复权重最大差<=1e-6；日物理残差<1e-6，保存成本与运行成本差<1e-6，主/重复全部数值指标差<1e-6，所选日成本与原实际日成本差<1e-6。另进程完整审计、来源哈希与CSV重建通过，年度重建绝对差<1e-6。任一异常即停止invalid，不把失败当方法反例。

保持原指标：E为年度消纳率与弃电率误差绝对值的最大值（百分点），D为load/wind/solar年度输入电量相对误差绝对值的最大值。三种子共同E<=1个百分点且D<=0.02方为双门槛通过；不新增成本准确性的绝对/相对标准。

主要探索性假设H：对于每个固定种子，新权重年度总成本误差绝对值和缺供误差绝对值，分别比原同种子U11R08B校准N48结果至少减少超过1e-6 CNY与1e-6 MWh，且全部E/D共同通过。三种子均符合则supported；至少一种子成本或缺供绝对误差明确增加超过相应1e-6，则refuted；其余情形（无明确反例但仅并列/未共同通过比例或电量门槛）为inconclusive。六项改善全量报告，不只挑seed7；此1e-6只辨别重建数值并列，不是工程精度目标。

结论只限当前构造算例、当前年/配置、已登记单代理方法；不外推跨年、极端日覆盖、任意容量、真实电网、容量最优、跨日SOC，也不证明代表日选择是唯一根因。旧研究的supported/inconclusive/invalid均不改。
