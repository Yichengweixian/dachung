# U06 MILP修订（执行前冻结）

用户明确批准将U06改为MILP、修正判定冲突并独立计入调度方法变化；仅本地执行，不推送。
本文优先于原LP设计及判据，保留原文。原数据和经济/储能/时间参数不变。

- 每时段增加二元变量 z：charge <= P*z，discharge <= P*(1-z)，允许两者均零。P取实际储能功率上限，禁止任意大常数。
- thermal_max仅从no_storage.json读取，新增optimization.json只含最小出力、爬坡率与目标项名称。
- PuLP+CBC，最小化原设计四项运行费用。投资和固定运维不进入调度目标。
- 验证独立于建模模块；严格检查原设计全部约束误差 < 1e-6，包括互斥和CSV读回。禁止截断、投影或修正求解输出掩盖残差。
- 证明Optimal且全部校验通过、差异可核对为supported。证明不可行为refuted；输入、环境、求解异常或验证错误为invalid；超时未证明最优或归因不明为inconclusive。所有非Optimal停止，不输出成功图表。
- 差异采用预定顺序：原规则→同物理边界MILP（最小出力0、无爬坡、末端自由）→加入最小出力→加入爬坡→加入期末归位。记录每步费用、电量变化，差值之和必须等于首尾差。各增量依赖顺序，不能称无交互的独立因果效应。
- 稳健性：48步dt=0.5重复小时值；E=P=0；原负荷保持、风光置零。零新能源时负荷峰值高于120MW，允许按原定义记录失负荷，不要求火电独自满足全部负荷。零储能仅与原规则进行边界不同的对照。
- 先通过已有25项测试，再冻结本文、原设计/判据/计划、输入与所有config文件SHA-256及内容。新增测试使用独立小算例与故意破坏结果检验。
