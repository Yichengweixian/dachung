# 执行计划草案

1. 用户先确认direction、N集合、种子、代表日规则及1个百分点/2%双门槛。未确认不得冻结或编写实验实现。
2. 冻结规则、原始年度输入、基准、配置和依赖；检查既有365日结果。原文件只读。
3. 用独立模块实现幅值特征和中心最近真实日，添加权重、零通道、日期平局与年度加权测试；保留旧src/annual_clustering.py行为。
4. 全矩阵求解，保存各簇成员、代表日期、距离、权重、输入电量误差、逐时解、日志和manifest；任一求解异常即停止。
5. 按同一N跨种子判据判定，更新本单元findings及台账；不自动进入U12R02。材料更新属于后续T4。
