# 原型执行边界（运行前冻结）

内置24h构造、168h NASA估计+构造负荷、8760h年度输入，并支持同字段CSV上传。
规则模式复用原有规则函数；MILP在<=168h时全段初末归位，>168h且为完整天时采用独立日模式，与U11口径一致。
年度模式必须明确无跨日耦合，不启动8760h单体MILP；输入最多8760行。
容量寻优固定24h输入和U09R01同一101候选集合；更长输入显示限制说明，不隐式截断或伪装全年寻优。
参数由冻结默认配置读取，用户改动仅在会话中使用，通过JSON导入/导出持久化，不写回冻结config。
上传数据和参数仅在本机处理；监听127.0.0.1，关闭使用统计，不部署或上传外部站点。
验收包含24h规则基准、24hMILP基准、168hCLI对照、101候选对照、CSV/PNG导出字节检查、空CSV/负容量错误，以及实际浏览器页面操作。
代理浏览器操作不冒充用户人工确认。人工确认尚未发生时总体inconclusive、工程待验收；功能测试失败则保留invalid证据。
