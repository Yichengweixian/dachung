# 方法规格（摘要）

细节以项目 docs 各阶段分析文档为准；本文件定义方法演进路线与各单元必须遵守的口径。

## 方法演进路线

| 阶段 | 方法 | 对应单元 |
|---|---|---|
| 已建基线 | 规则调度：新能源优先、火电补缺；储能富余充电/缺电放电 | U01—U05 |
| 调度优化 | **混合整数线性规划（MILP）**：PuLP+CBC，运行成本最小，含火电最小出力/爬坡/期末 SOC 归位和充放互斥 | U06 |
| 深化 | 独立验证与差异归因 | U07 |
| 场景 | 渗透率矩阵（4 系数 × 3 储能，MILP 批量） | U08 |
| 寻优 | **网格搜索 (E×P)**：仿真/评价/寻优三层分离，综合成本最小 | U09 |
| 数据 | NASA POWER 真实气象 → 物理转换 → 168h | U10 |
| 尺度 | 8760h + k-means 典型日聚类（含权重） | U11 |
| 增强 | 遗传算法/粒子群，与网格基准对照 | U12 |
| 落地 | Streamlit 软件原型；报告/论文/专利材料 | U13/U14 |

## 调度模型口径（U06 起）

- 目标 = 火电成本 + 弃电惩罚 + 失负荷惩罚 + 储能可变运维（运行层）；储能投资折算属**评价层**（U09），不进入调度目标。
- 约束：功率平衡、火电上下限与爬坡、风光消纳+弃电=可用、SOC 递推与上下限、期末 SOC=初始 SOC、充放功率上限。
- 求解器状态非 Optimal 必须停止，不得产出图表或结论。

## 经济评价口径（沿用 docs/economics_analysis.md）

- 综合成本 = 火电 + 储能（年化投资分摊 + 固定/可变运维）+ 弃电惩罚 + 失负荷惩罚。
- 年化：I × CRF × (仿真小时/8760)；CRF = r/[1−(1+r)^(−n)]。
- 初始库存影响单独列示，不得计入"当日收益"。

## 验证方法（所有单元通用）

1. 约束残差检查（平衡、SOC、爬坡、分解恒等式）——检查脚本不得与模型实现共用代码路径；
2. CSV 存盘后读回再校验；结果图必须用读回数据绘制；
3. 手算 oracle（独立小算例核对分支）；
4. 证据三元组：脚本 + 参数 + 依赖版本，附 run_manifest.json（输入 SHA-256、参数快照、环境）。
