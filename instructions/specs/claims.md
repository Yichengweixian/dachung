# 论断登记

## 登记规则

1. 只有 **confirmatory 模式 + supported** 的结果可以登记；exploratory 单元一律不登记。
2. 每个论断必须附：单元编号、证据三元组（脚本 + 参数 + 版本）、run_id、输入与判据哈希、预写措辞。
3. 否定与不确定结果不登记为论断，但必须在单元 findings 中完整保留。
4. 已执行单元要改变论断 → 新建单元，不得在原单元上改写。
5. 汇报 PPT、论文与报告中的数字结论只允许引用本表与各单元 findings 中的 supported 结果；历史基线（U01—U05）只能标注"历史基线，判据事后整理"。
