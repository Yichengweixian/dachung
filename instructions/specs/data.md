# 数据规格（摘要）

细节以项目 `docs/data_description.md`（24h 构造数据）与 `docs/metric_definitions.md`（字段与口径）为准；本文件只列执行包需要的要点，二者冲突时以本文件记录的口径决定为准并回写 docs。

## 输入字段（data/input_24h.csv）

| 字段 | 含义 | 单位 |
|---|---|---|
| hour | 区间起点，0—23，连续不重复 | 小时 |
| load | 该小时平均负荷 | MW |
| wind / solar | 风光**可用出力**（未扣除弃电） | MW |

## 结果字段（各阶段 output 通用口径）

| 字段 | 含义 |
|---|---|
| renewable / renewable_used / curtailment | 风光总可用 / 实际消纳 / 弃电（MW）；U06 起按风、光分列 used 与 curt |
| thermal | 火电出力（MW） |
| storage_charge / storage_discharge | 电网侧充/放电功率（MW，正值） |
| energy_MWh / soc | 电池侧电量（MWh）与 SOC（0—1），二者不混用；N 个时段对应 N+1 个状态边界 |
| unserved / load_shedding | 失负荷功率（MW） |
| balance_error_MW | 功率平衡残差（MW），须 ≈ 0 |

## 单位与计算口径

- 功率 MW、电量 MWh；时段电量 = 平均功率 × 步长 dt 后求和。
- 消纳率 = 消纳电量 ÷ 可发电量 × 100；弃电率 = 1 − 消纳率；可发电量为 0 时记空值"不适用"。
- 消纳量包含进入储能的电量（含后续损耗），不等于最终供负荷的新能源电量。
- SOC 与剩余电量分开记录；零容量场景 SOC 未定义，用空值。

## 数据目录

| 目录 | 用途 |
|---|---|
| data/raw/ | 原始下载数据与来源记录（U10 起使用） |
| data/processed/ | 清洗/转换后的模型输入 |
| data/scenarios/ | 场景参数与配置表（U08 渗透率矩阵等） |
| data/input_24h.csv | 当前 24h 构造算例（seed 20260910，装机：风 100 / 光 150 MW，峰荷 162 MW） |

## 数据来源计划（U10/U11）

- 气象：NASA POWER 免费 API，武汉坐标（30.59°N, 114.30°E），逐小时辐照度与风速；原始返回文件必须存档，转换脚本入库。
- 风电：风速经切入/额定/切出三段式功率曲线转标幺出力 × 装机。
- 光伏：辐照度经简化模型转标幺出力 × 装机。
- 负荷：公开曲线归一化取形状 × 本算例峰荷；**明确标注为构造形状，不得称真实负荷**。
- 所有真实数据文档必须记录：来源、坐标、时间范围、单位、转换公式、局限性与复现方法。
